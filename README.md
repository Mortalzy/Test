# Test — галерея интерактивных идей

Галерея компонентов из 21st: два варианта глобуса, точечный фон с розово-фиолетовым следом курсора Interactive Background с кинетической сеткой и Pixel Flow Field.

## Переключение идей

Стрелки слева и справа экрана, а также клавиши `←` / `→` переключают идеи по кругу. Внизу отображаются название и номер. Если фокус установлен на Canvas первого глобуса, стрелки клавиатуры сохраняют управление его вращением. При переключении предыдущий эффект размонтируется и освобождает ресурсы.

- `/?idea=pixel` (или `/`) — Pixel Flow Field: пиксельное слово с реакцией на курсор и настройками.
- `/?idea=custom` — глобус, вариант 1.
- `/?idea=original` — глобус по оригиналу 21st.
- `/?idea=kinetic` — Interactive Background: тёмная сетка из предоставленного промпта, синяя подсветка и притяжение к указателю, расходящиеся волны при нажатии.
- `/?idea=trail` — Dotted Trail Cursor: белый фон, серая сетка и розово-фиолетовый след курсора. След затухает при остановке. Работает с мышью и касанием; при `prefers-reduced-motion` остаётся статичная сетка.

Выбор сохраняется в URL; обновление страницы и кнопки «Назад» / «Вперёд» браузера восстанавливают идею. Старые ссылки `?variant=custom` и `?variant=original` тоже работают.

Новый компонент: `components/ui/dotted-trail-cursor.tsx`, демо: `components/dotted-trail-demo.tsx`, список идей: `lib/ideas.ts`. WebGL-шейдер перенесён из предоставленного промпта без изменения цветов и алгоритма. Провайдеры, внешние изображения и новые npm-пакеты не нужны. Для эффекта требуется WebGL 2; без него показываются статичная сетка и пояснение. Источник компонента: Hyperiux Vault, ссылка сохранена в его коде.

## Pixel Flow Field

Пятая идея, открывается по умолчанию: `/` или `/?idea=pixel`. Исходный компонент из промпта находится в `components/ui/pixel-flow-field.tsx`, демо — в `components/pixel-flow-field-demo.tsx`.

Светлый фон, слово `smooth`, серая сетка и розовый акцент сохраняют исходную палитру. Цветовые переменные ограничены `.pixel-flow-demo`, чтобы остальные идеи сохранили свои темы. Кнопка «Настройки» открывает текст (до 24 символов), формы «Квадраты / Круги / Крестики», размер, промежуток, скорость, радиус и силу курсора, толщину букв. Цвет фона и цвет фоновых кубиков меняются независимо; палитра букв при этом сохраняется. «Рассыпать» повторяет сборку, «Пауза» замораживает текущий кадр, «Сбросить настройки» возвращает параметры из промпта. При переключении идеи демо начинает работу с исходными параметрами.

```tsx
import PixelFlowField from "@/components/ui/pixel-flow-field"

<PixelFlowField className="h-svh w-full" text="smooth" shape="square" />
```

Добавлена зависимость `motion` для `useReducedMotion`; дополнительные провайдеры и изображения не нужны. Компонент поддерживает `children`, `colors`, `src` и остальные props из промпта. Для `src` нужен доступ к пикселям изображения через CORS; демо использует текст без внешних запросов.

Canvas адаптируется к размеру контейнера, учитывает DPR до 2 и ограничивает плотность сетки. При `prefers-reduced-motion` показывается неподвижный рисунок. В скрытой вкладке или вне экрана анимация приостанавливается; при продолжении её время не перескакивает. Pointer Events поддерживают мышь и касания. Наблюдатели, обработчики и RAF освобождаются при размонтировании.

## Interactive Background — Kinetic Grid

Компонент: `components/ui/kinetic-grid.tsx`, демо: `components/kinetic-grid-demo.tsx`. Это четвёртая идея в галерее. Демо сохраняет заголовок, цвета, шаг сетки 55 px, радиус влияния 260 px и алгоритм деформации из присланного промпта.

```tsx
import KineticGrid from "@/components/ui/kinetic-grid"

<KineticGrid globalColor="default">
  <div className="flex min-h-svh items-center justify-center text-white">
    Move your cursor. Click anywhere.
  </div>
</KineticGrid>
```

`children` задаёт содержимое поверх фона, `className` — стили контейнера. `globalColor="monochrome"` включает чёрный фон и белую подсветку вместо исходного тёмно-серого фона с синей подсветкой. Новые пакеты, провайдеры и изображения не требуются.

Canvas учитывает размеры контейнера и плотность пикселей экрана. Pointer Events поддерживают мышь, перо и касания; волна появляется при нажатии. При уходе указателя подсветка сбрасывается. В скрытой вкладке анимация приостанавливается, при `prefers-reduced-motion` показывается статичная сетка. Все обработчики, ResizeObserver и цикл анимации очищаются при переключении идеи и в React Strict Mode.

## Два варианта

- `/?variant=custom` — первая версия с адаптивностью, сенсорным управлением и кнопками.
- `/?variant=original` — второй вариант по исходному коду из 21st: Canvas 800 × 600, радиус `min(width, height) / 2.5`, вращение 0.5° за кадр, исходная сетка, точки с шагом 1.28°, контуры и подпись `Drag to rotate • Scroll to zoom`. Без шапки, подвала и дополнительных кнопок управления.

Стрелки по краям экрана позволяют сравнить варианты. Исходный вариант реализован отдельно в `components/ui/wireframe-dotted-globe-original.tsx`; он сохраняет особенности оригинального алгоритма, в том числе отрисовку точек обратной стороны, масштабирование колёсиком и управление мышью. Изменения ограничены типами TypeScript, очисткой ресурсов и загрузкой тех же данных из локального файла. Оригинальная версия рассчитывает размер при монтировании; после изменения окна можно обновить страницу. На телефоне для перетаскивания используйте первый вариант.

## Запуск

Нужен Node.js 22.12+ (или 24) и npm.

```bash
git clone https://github.com/Mortalzy/Test.git
cd Test
npm ci
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173).

```bash
npm run build
npm run preview
```

Первая команда проверяет TypeScript и создаёт production-сборку в `dist/`, вторая запускает её локально.

## Структура

- `components/ui/wireframe-dotted-globe.tsx` — компонент глобуса.
- `components/demo.tsx` — пример подключения.
- `src/main.tsx` — страница демо.
- `src/index.css` — Tailwind CSS 4 и переменные темы.
- `lib/globe-geometry.ts` — генерация точек с учётом отверстий в полигонах.
- `lib/utils.ts` — стандартный shadcn-хелпер `cn`.
- `public/data/land.geojson` — локальные географические данные Natural Earth.

Проект настроен на React, TypeScript, Tailwind CSS 4. `components.json` содержит конфигурацию shadcn, алиас `@` указывает на корень проекта. Папка `components/ui` хранит переиспользуемые UI-компоненты; CLI shadcn использует её при добавлении компонентов, поэтому импорты остаются единообразными. Настраивать TypeScript или Tailwind заново не нужно.

При необходимости можно добавлять компоненты:

```bash
npx shadcn@latest add button
```

## Использование

```tsx
import RotatingEarth from "@/components/ui/wireframe-dotted-globe"

export default function Demo() {
  return <RotatingEarth width={800} height={600} className="mx-auto w-full" />
}
```

`width` и `height` ограничивают размер Canvas. Компонент подстраивается под контейнер и высоту окна. Провайдеры, ключи API, сервер и база данных не требуются.

## Управление

- Мышь или касание с перетаскиванием: вращение.
- Колёсико и кнопки `+` / `−`: масштаб от 0.5× до 3×.
- Пауза: остановка или продолжение автоматического вращения.
- Сбросить: восстановление начального положения и масштаба.
- Когда Canvas в фокусе: стрелки вращают, `+` / `−` меняют масштаб, `0` сбрасывает положение.

Автовращение учитывает `prefers-reduced-motion`. Обработчики, таймер, ResizeObserver и загрузка данных очищаются при размонтировании, включая React Strict Mode. Точки обратного полушария не рисуются. Щипок двумя пальцами не реализован; на телефоне масштаб меняется кнопками.

## Данные

Данные Natural Earth находятся в общественном достоянии. Исходный компонент предоставлен пользователем; происхождение и условия его использования см. на странице компонента в 21st.
